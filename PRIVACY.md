# Privacy

Process Tabs does not collect, transmit, sell, or share user data.

The extension has no analytics, telemetry, advertising, remote API, login, or cloud service of its own.

Process names and file URIs are stored using VS Code `workspaceState` so each workspace can remember its own processes. This data remains under the storage behavior of the editor in which the extension is installed.

Process Tabs does not read file contents for analytics or transmission. It opens, closes, and tracks editor tabs through the VS Code Extension API in order to provide its core functionality.
